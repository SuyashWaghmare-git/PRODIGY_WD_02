# ⏱️  — Modern Stopwatch App

This is a **modern stopwatch web app** I built using **React, TypeScript, Vite**, and **Tailwind CSS**.  
It combines a **sleek, futuristic digital design** with a touch of **classic analog style**.

I made this project as part of my **web development internship at Prodigy InfoTech** to strengthen my frontend development and UI design skills.  
It helped me understand how to structure a React app, manage time-based logic, and create smooth, responsive designs.

---

## 🚀 Features

- 🕒 Start, pause, and reset stopwatch  
- ⚡ Super-fast development setup with **Vite**  
- 🎨 Clean and modern UI with **Tailwind CSS**  
- 📱 Fully responsive — works on desktop and mobile  
- 🧩 Built with **React + TypeScript** for scalability  
- 💡 Simple, minimal, and easy to use

---

## 🧩 Tech Stack

| Tool | Purpose |
|------|----------|
| **React (TypeScript)** | Component-based frontend |
| **Vite** | Fast bundling and dev server |
| **Tailwind CSS** | Modern utility-first styling |
